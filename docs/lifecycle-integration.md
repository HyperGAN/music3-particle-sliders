# Music3 owned factory draft

Historical first-pass notes at `f64874b`. The newer
[response-session proposal](response-session-proposal.md) adopts the reviewed
neutral contract and supersedes the image-registration/profile/module blockers
below. The first source receipt remains evidence only for that original draft.

This is a new, opt-in source draft based on PR5 at
`471a7c9669fa30f19ec318f0fc6b39bd1de833c1`. It preserves PR5's package loader,
requirements, lock, CLI routes, checkpoint schemas and evidence unchanged.
PR3 at `2f1ff5a952b2c3e81365ba2aeeeb5edd94fcd76b` remains an independent
FormulationGame host-bridge payload. Neither draft is merged or superseded.
Default main `b40d2aa6fed745eda3043d3d3b11e362ec2f8dfe` was inventory evidence;
it was not used to discard either unmerged payload.

`music3.lifecycle.describe(options)` supplies an allocation-free AR response
contract. `prepare(options)` owns actual random Qwen3 construction or offline
native loading, the existing shared Music3 ParticleNetwork, frozen paired
teachers, complete context conditions, AudioResponseCritic, ConditionalPG09
and exact hook/checkpoint/mode/gradient cleanup on failure and close. It returns
the shared Binding; it introduces no product session, GAN mathematics,
optimizer, prior, renderer or checkpoint implementation.

The response stays `[1, hidden_size]`, with no projection or field reshape.
The student receives neutral caption/lyrics plus exactly the same supplied
continuation tokens as the positive teacher. Native text cleaning/assembly
uses the existing Diffusers Music3 functions through shared native utilities.
The last prompt token must be the genuine audio-start marker 151669; supplied
history follows that marker. No continuation history is generated by this
factory. There is no diffusion scheduler in this AR-hidden response arm.

The generator retains the participating 128x4 particle parameter from the
actual hooked attention adapter. It is passed by identity to the core prior,
which owns optimizer deduplication. Adapter trainables remain FP32. Native
base weights remain BF16; the tiny random fixture is CPU FP32. Width 4096
requires the explicit reviewed `alz-continuous-v1`/`continuous` source pair,
checked against actual installed PG bytes before allocation. No overlay is
installed or selected by this change. Strength support remains finite [0,1].
Transformer, encoder, image references, signed extrapolation and acoustic/token
rendering are refused. A hidden response is never labeled a waveform or image.

Native options require the existing staged `manifest`, its reviewed
`manifest_sha256`, a local `model_dir`, and paired caption/lyrics `rows`.
The manifest must name revision
`bd348f9c49ea3c1b39f33ace3436f8fad435f24e` and exactly cover all LM/tokenizer
files. Config identity is checked before allocation; prepare streams the
recorded file digests before using local-only, non-remote-code, safetensors
loaders. Acoustic model files are outside this factory's ownership. No model
or pretrained file was loaded during this source-edit task.

## Interface blockers for the parent

1. Milestone `fd89e1c780ab5210cd1be98ec3b70977e6349379` hardcodes
   `particle-sliders-image-session-v1`, `particle_sliders.image_backends`,
   reference-image vocabulary and PIL/latent rendering defaults. Music3 needs
   a modality-neutral public registration and packet contract with explicit
   `audio_ar_hidden` / `continuous_vector` / `native_final_ar_hidden` identity.
   This draft intentionally has no image registration and exposes no new CLI.
   The parent should coordinate that common API change, then bind this factory
   through the shared Backend and public session rather than inventing a local
   lifecycle. The factory is not an activated public migration.
2. The milestone package does not contain `particle_sliders.pg09_audio_cli`,
   required by PR5's verified 0.6.0 bootstrap. Updating its pin to 0.7.0 would
   break the preserved CLI. Retain its exact lock until the owner supplies the
   reviewed common package/source/wheel contract; use a new cohort for this
   factory. Do not relabel PR5 checkpoint receipts as lifecycle qualification.
3. `Backend.open` in the milestone unconditionally calls `_released_sources()`
   with the default release before factory preparation. A genuine width-4096
   Music3 factory requires the explicit reviewed continuous source profile.
   Generic preflight must honor the configured profile with the matching
   declared response domain, without changing active environments.
4. Shared dependency-direction guard omits bare product package names `music3`
   and `yue2`; add these to the common deny set. This factory imports only core
   and native dependencies; no reverse import or path injection is introduced.
5. HNDL conversion of AudioResponseCritic (Linear/SiLU/Linear), ParticleNetwork
   LoRA leaves and RoutedMLP remains pending common matched-weight state mapping
   and actual-update/regularizer parity. This draft deliberately retains the
   existing network definition and does not choose an arbitrary new critic law.
   Pretrained Qwen3 is an external native backbone, not a network rewrite target.
6. Shared `assert_audio_start` silently permits a tokenizer with no resolvable
   marker. This draft explicitly requires token 151669 for the pinned native
   tokenizer. Any general helper fix should preserve legacy loader behavior.

HyperGAN owns run presentation through session on_step/manifest/artifact seams.
A future qualified native audio sampler must be a separate product callback
using the same adapter. No dashboard or substitute audio decoder is included.
The core owner's compact inference loader and clean-main candidate are separate
follow-ups; this draft preserves the exact supplied milestone identity.
