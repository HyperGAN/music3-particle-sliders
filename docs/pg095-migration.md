# PG0.9.5 migration

Root0.3.0 binds core0.13.0 commit3dd672a, official PG0.9.5 and its full577-file source closure. The backend delegates to ConditionalPG095. Native width4096 uses release-0.9.5/continuous and protocol music3-native-final-ar-hidden-v2-pg095 with music3-bf16-eager-strict-pg095-v1.

Frozen model assets, BF16 geometry, constructor policy, private RNG, bank/adapter shapes and inherited defaults remain unchanged. No GAN math is copied. Historical source archives, standalone CLI, locks, published weights and old checkpoint environments are untouched; old-source rates are not current recommendations.

CPU checks cover actual small model/provider/critic/prior preparation, exact fresh continuation, raw/EMA native-only artifacts, source refusal and numerical/RNG ownership. Pretrained PG0.9.5 native proof and LR measurement remain pending. These checks load no full pretrained model or CUDA context.
